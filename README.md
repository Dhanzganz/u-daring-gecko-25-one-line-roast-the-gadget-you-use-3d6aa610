# One-Line Roast: The Gadget You Use Every Day

A single original line roasting the phone I use every day — its battery
health is 78%, it dies faster than my motivation, and it still judges me
with 1% left like it planned the drama.

Running `main.py` writes the roast to `/output/entry.txt`.

Output path: `/output/entry.txt` (the program verifies the file after writing it).
